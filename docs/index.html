1. Axis Choices and Physical Meaning

1.1 2θ — the instrument's measured angle

Meaning: This is the raw diffraction angle directly measured by the diffractometer.

Limitation: 2θ depends strongly on the X-ray wavelength λ. If one dataset uses Cu Kα (λ ≈ 1.54 Å) and another uses Mo Kα (λ ≈ 0.71 Å), the same crystal will produce peaks at very different 2θ positions, so the two patterns cannot be directly overlaid without conversion. [1]

1.2 d-spacing — the crystal's fingerprint

Formula:

$$d = \frac{\lambda}{2\sin\theta}$$

Meaning: $d$ is the physical spacing between lattice planes in the crystal, usually expressed in angstroms (Å).

Use: This is an intrinsic property of the material. No matter what wavelength is used, the same crystal gives the same $d$-spacing values. That is why reference databases such as JCPDS or ICDD PDF cards are commonly matched using $d$-spacing rather than 2θ. [2]

1.3 q — the reciprocal-space language

Formula:

$$q = \frac{4\pi\sin\theta}{\lambda}$$

Meaning: $q$ is the magnitude of the scattering vector in reciprocal space, describing the momentum transfer during diffraction.

Use: In SAXS, WAXS, neutron diffraction, and synchrotron work, $q$ is often used as the standard x-axis because it allows data collected with different wavelengths to be compared on the same scale. [3]

1.4 sinθ/λ — the crystallographic working variable

Meaning: This is equivalent to $1/(2d)$, or $q/(4\pi)$.

Use: In crystallography, atomic scattering factors are often discussed as functions of $\sin\theta/\lambda$, making this a convenient standard variable for refinement and structure analysis.

In the app, all four representations are selectable from the same dropdown (“X-axis:”) in both Window A and Window B. See §8 for how the app converts between them.

2. Bragg's Law

Formula:

$$n\lambda = 2d\sin\theta \quad (n=1)$$

Where:

  • λ = X-ray wavelength (Å)
  • d = interplanar spacing (Å)
  • θ = Bragg angle, half of the measured 2θ

2.1 Uses in the code

d → θ: predicts where a peak should appear:

$$\theta = \arcsin\left(\frac{\lambda}{2d}\right)$$

Then the plotted peak position is 2θ. Implemented in calculate_bragg_angle(wavelength, d_spacing). If $\lambda/(2d) > 1$ or $d \le 0$, the reflection is physically unreachable at that wavelength and the function returns None, so it is simply skipped when scanning h/k/l space.

θ → d is not used directly, but the inverse relation is used when converting a measured pattern from one wavelength to another (§5) and when converting between axis display modes (§8).

3. Interplanar Spacing: General Triclinic Formula

Because triclinic is the lowest-symmetry crystal system, its $d$-spacing formula is the most general one and can also describe higher-symmetry systems by applying symmetry constraints such as $\alpha = \beta = \gamma = 90^\circ$. For this reason, the code implements only the triclinic case in CrystalSystemCalculator.triclinic, and every crystal system is entered simply by typing the appropriate a/b/c/α/β/γ values.

3.1 Unit-cell volume

$$V = abc\sqrt{ 1-\cos^2\alpha-\cos^2\beta-\cos^2\gamma +2\cos\alpha\cos\beta\cos\gamma }$$

3.2 Reciprocal spacing

$$ \frac{1}{d^2} = \frac{ h^2b^2c^2\sin^2\alpha + k^2a^2c^2\sin^2\beta + l^2a^2b^2\sin^2\gamma + 2hkabc^2(\cos\alpha\cos\beta-\cos\gamma) + 2kla^2bc(\cos\beta\cos\gamma-\cos\alpha) + 2hlab^2c(\cos\alpha\cos\gamma-\cos\beta) }{V^2} $$

Where:

  • a, b, c = unit-cell edge lengths (must be > 0)
  • α, β, γ = unit-cell angles between 0° and 180°
  • h, k, l = Miller indices, scanned over ±20 for each index

If the square-root term, which is the cell-volume term, is not positive, or the resulting volume is not positive, the function raises a ValueError rather than silently continuing. If $1/d^2 \le 0$, the reflection is treated as nonexistent, with $d = \infty$. Implemented in CrystalSystemCalculator.triclinic( h, k, l, a, b, c, alpha_deg, beta_deg, gamma_deg ) .

Friedel pairs $(h,k,l)$ and $(-h,-k,-l)$ have identical d-spacing, so the reflection scan (_iter_theoretical_reflections) keeps only one representative of each pair to avoid duplicate peaks.

4. Systematic Absences

A reflection allowed by Bragg's law may still be absent because of crystal symmetry. These are called systematic absences. The program checks three independent sources of absence; a reflection is marked absent if any rule forbids it. [4]

4.1 Lattice Centering

Lattice type Symbol Condition for reflection to be allowed
Primitive P always allowed
Body-centered I $h+k+l = 2n$
Face-centered F h, k, l all even or all odd
A-centered A $k+l = 2n$
B-centered B $h+l = 2n$
C-centered C $h+k = 2n$
H-centered (hexagonal obverse) H $(h-k) \bmod 3 = 0$
R-centered, obverse setting R (obv) $(-h+k+l) \bmod 3 = 0$
R-centered, reverse setting R (rev) $(h-k+l) \bmod 3 = 0$

Implemented in lattice_forbidden(h, k, l, lattice_type).

4.2 Screw Axes

A screw axis affects only axial reflections along its own axis: $h00$ for the a-axis, $0k0$ for the b-axis, and $00l$ for the c-axis. For such reflections, the index along the screw axis must satisfy:

Screw axis Condition for the axial index to be allowed
$2_1, 4_2, 6_3$ index is even
$3_1, 3_2, 6_2, 6_4$ index mod 3 = 0
$4_1, 4_3$ index mod 4 = 0
$6_1, 6_5$ index mod 6 = 0

The index 0 itself, that is, the origin-adjacent reflection along that axis, is never treated as forbidden. Implemented in screw_axis_forbidden(h, k, l, axis, screw_rule).

4.3 Glide Planes

A glide plane perpendicular to an axis affects only zonal reflections with that axis index equal to zero: $0kl$ perpendicular to a, $h0l$ perpendicular to b, and $hk0$ perpendicular to c. For the remaining two indices $u$ and $v$:

Glide type Condition for u, v to be allowed
a-glide u is even
b-glide index along b is even
c-glide index along c is even
n-glide $u+v$ is even
d-glide $u+v$ is divisible by 4

Implemented in glide_plane_forbidden( h, k, l, plane_perp_axis, glide_rule ) .

4.4 Combining the Rules

A reflection is classified as:

  • absent if lattice_forbidden OR any of the three screw_axis_forbidden checks OR any of the three glide_plane_forbidden checks is true.
  • allowed otherwise.

Implemented in systematic_absence_reasons(...) and classify_reflection(...).

5. Wavelength Conversion of a Measured Pattern

When a pattern measured at wavelength $\lambda_1$ needs to be displayed as if it were measured at wavelength $\lambda_2$, the d-spacing of each peak remains physically constant. Bragg's law is therefore applied twice:

$$\lambda_1 = 2d\sin\theta_1$$ $$\lambda_2 = 2d\sin\theta_2$$

Therefore:

$$\sin\theta_2 = \left(\frac{\lambda_2}{\lambda_1}\right)\sin\theta_1$$

and:

$$\theta_2 = \arcsin\left[ \left(\frac{\lambda_2}{\lambda_1}\right)\sin\theta_1 \right]$$

Thus:

$$ 2\theta_2 = 2\arcsin\left[ \left(\frac{\lambda_2}{\lambda_1}\right) \sin\left(\frac{2\theta_1}{2}\right) \right] $$

If $|(\lambda_2/\lambda_1)\sin\theta_1| > 1$, the peak has no valid angle at the new wavelength and is marked invalid (NaN). Implemented in _convert_two_theta_by_wavelength( two_theta_deg, lam_from, lam_to ) .

6. Zero-Shift Correction

A simple additive correction is applied to compensate for instrument misalignment:

$$2\theta_{\text{corrected}} = 2\theta_{\text{converted}} + \Delta 2\theta$$

Here, $\Delta 2\theta$ is the zero-shift offset in degrees. It updates the plot in real time and is applied to the theoretical peak positions, not the measured data.

7. Overlay Window (Window B)

These are display-only transformations used for comparing multiple curves; they are not physical formulas.

7.1 Normalization

$$y_{\text{norm}} = \frac{y-y_{\min}}{y_{\max}-y_{\min}}$$

Toggled with the “Normalize (0–1)” checkbox; rescales each curve to its own min/max range independently.

7.2 Vertical scaling and shifting

$$y_{\text{display}} = y \cdot \text{scale} + y_{\text{shift}}$$

The Y-offset step is applied per curve as $y_{\text{shift},i} = \text{offset} \times i$, producing an automatic waterfall stack.

7.3 Interactive drag-to-reposition

Clicking and dragging a curve vertically in Window B directly edits its y_shift in real time.

7.4 Per-curve zero shift in Window B

Independently of the zero shift in Window A, each overlay curve can carry its own $\Delta 2\theta$ offset:

$$2\theta_{\text{shown}} = 2\theta_{\text{sent}} + \Delta 2\theta_{\text{curve}}$$

8. X-axis Display-Mode Conversion

Both plot windows let the x-axis be displayed as 2θ, $d$-spacing, $\sin\theta/\lambda$, or $q$. Internally, every peak and every data point is stored as 2θ in degrees.

8.1 Forward: 2θ → display mode

Mode Formula
2θ (deg) identity
d-spacing (Å) $d = \lambda/(2\sin(\theta))$
sin(θ)/λ (Å⁻¹) $\sin\theta/\lambda$
q (4π·sinθ/λ) $4\pi\sin\theta/\lambda$

8.2 Inverse: display mode → 2θ

Used whenever the user interacts directly with the plotted x-axis. Each conversion is the algebraic inverse of the forward conversion.

$$ 2\theta = \begin{cases} 2\arcsin\left(\dfrac{\lambda}{2d}\right) & \text{from } d\text{-spacing} \\[6pt] 2\arcsin\left(v\lambda\right) & \text{from } \sin\theta/\lambda=v \\[6pt] 2\arcsin\left(\dfrac{v\lambda}{4\pi}\right) & \text{from } q=v \end{cases} $$

9. Interactive Peak Alignment

Rather than typing a numeric zero-shift, the plot supports a two-click workflow to solve for it directly from a visual misalignment:

  1. First double-click near a theoretical peak to select that peak.
  2. Second double-click anywhere on the plot to select the target x-position.

The new zero shift is solved as:

$$\Delta 2\theta_{\text{new}} = 2\theta_{\text{target}} - 2\theta_{\text{source}}$$

This is separate from the single-click pin/unpin hkl label behavior, which only toggles a persistent index label on a peak.
